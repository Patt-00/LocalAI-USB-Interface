PORTABLE DESKTOP AGENT
----------------------
The official llama.cpp website was extended and built locally to provide:
- read, recursive file search, text search, shell, write, and exact-edit tools;
- access to all files the signed-in OS user can legitimately access;
- Allow once, Always allow this tool, Always allow all Server Tools, and Deny;
- working-directory selection and alternate compatible GGUF discovery from
  LocalAI-Models, Desktop, and Downloads without copying those models;
- PDF text, DOCX text, text/source uploads, local chat history, and automatic
  semantic compaction of older agent turns while retaining full local history;
- one-model-at-a-time routing, performance-oriented defaults, and no background
  indexer or additional always-on service.

Access never bypasses root, sudo, UAC, Gatekeeper, Android app isolation,
encryption, permissions, or policy. The included Qwen3 model is text-only.
Images require a compatible vision GGUF plus its matching mmproj. Scanned PDFs
require OCR or a compatible vision model. No dependable lightweight web-search
backend is bundled; an installed command such as curl can use the Internet only
after the user approves it and explicitly requests the network action.

SECURITY AND PRIVACY
--------------------
Every desktop start generates a new 32-byte API key in private temporary state.
The key is passed by API-key file, not exposed in the server command line, is
bootstrapped through a URL fragment, and is immediately removed from browser
history. The raw agent-tool endpoint returns HTTP 401 without that key. All
servers bind to loopback, never 0.0.0.0. Normal chat/inference is offline and no
cloud API, account, telemetry, or API key from an external service is required.
PID plus process identity/command checks ensure STOP targets only the server
created by this USB. POSIX servers use nohup and redirected input/output so they
remain safe when a launcher terminal closes.
